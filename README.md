# 桌面小鱼宠物 🐟

一个 Windows 桌面宠物小程序，用《捕鱼达人》风格的鱼素材做成。小鱼会在屏幕上自由游动，可以拖动、点逗，还能在系统托盘里右键管理。

## 功能特性

- **逐像素透明窗口**：基于 Win32 `UpdateLayeredWindow` 实现，边缘无毛边，透明区域鼠标点击自动穿透，不挡桌面操作。
- **自然游动**：小鱼在屏幕工作区内自由游动，随机转向 / 停留 / 猛冲，贴边反弹。
- **鼠标交互**：
  - 左键拖动：把鱼放到任意位置。
  - 轻点一下：鱼会受惊猛窜。
- **右键菜单 / 系统托盘**：更换品种、调整大小、添加 / 移除小鱼、退出。
- **多鱼共存**：可同时养多条鱼，配置保存在 `fish_pet_config.json`。
- **繁殖系统**：鱼随运行时间自动升级成长，达到「成年」（Lv6）后可在附近生小鱼——成年鱼每隔约 120 秒自动生育，也可右键「生一条小鱼」立即生育。生育为自然行为，**不消耗金币**，每次随机生 1~4 条，仅受鱼池上限约束。

## 环境要求

- Windows 系统
- Python 3.8+（自带 `tkinter`）
- 第三方依赖：
  - `Pillow >= 10.0`
  - `pystray >= 0.19`

## 安装与运行

### 方式一：双击启动（推荐）

直接双击 `启动小鱼.bat` 即可。脚本会自动优先用 `pythonw` 无控制台方式启动；若没有 `pythonw` 则回退到 `python`。

### 方式二：命令行

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 运行
python desktop_fish_pet.py
```

## 配置说明

配置文件为 `fish_pet_config.json`，程序退出时自动保存当前状态。

```json
{
  "fish": [
    {
      "path": "新版鱼\\huangjinsha",  // 鱼素材目录（位于 鱼/ 下）
      "scale": 0.7,                   // 缩放比例
      "x": 297,                       // 初始横坐标
      "y": 451                        // 初始纵坐标
    }
  ],
  "coins": 623,        // 金币（预留玩法数据）
  "cannon_level": 1    // 炮台等级（预留玩法数据）
}
```

### 添加新鱼种

鱼的素材放在 `鱼/` 目录下，每个品种一个子文件夹（如 `鱼/新版鱼/huangjinsha`、`鱼/中型鱼/hujing`）。通过右键菜单“添加小鱼”即可选用，无需手动改配置文件。

## 文件结构

```
fish/
├── desktop_fish_pet.py    # 主程序
├── 启动小鱼.bat            # 一键启动脚本
├── requirements.txt       # Python 依赖
├── fish_pet_config.json   # 运行时配置（自动保存）
└── 鱼/                    # 鱼素材目录（按品种分子目录）
```

## 使用提示

- 右键点击任务栏托盘图标或小鱼本身，可打开管理菜单。
- 想让鱼完全不挡操作：拖动到角落，或直接在菜单里移除多余的小鱼。
- 高 DPI 屏幕下程序会自动适配，保证坐标 1:1，不会出现偏移或缩放错位。
